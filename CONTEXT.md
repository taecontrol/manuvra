# Manuvra vocabulary

> This vocabulary is being rebuilt; Job, Step, Done condition, Run, Escalation, Disposition, and Verdict will be added by the architecture brief.

**Manuvra**:
The browser flow executor in this repository.

**Target**:
The Chromium page under Manuvra's control.

**Outcome**:
The factual disposition of an attempted operation: `observed`, `not_performed`, or `uncertain`. It does not assert that an application-level semantic effect occurred.

**Artifact**:
A run-owned evidence file, such as a snapshot or screenshot, retained according to the run's evidence policy.
